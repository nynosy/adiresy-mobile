Privacy Policy

Adiresy – Android app (org.github.nynosy.adiresy_mobile)

Last updated: 15 August 2026

Summary: Adiresy does not require an account, and contains no analytics, tracking, or advertising SDKs. Location data is only sent when you explicitly trigger an action (e.g. "Locate me", tapping a building, a nearby search) — there is no background location tracking. Favourites, search history, and downloaded map data stay only on your device.

3. What data is processed

3.1 Location data (GPS)

The app requests the ACCESS_FINE_LOCATION and ACCESS_COARSE_LOCATION permissions. Location is only accessed in the foreground and only when you explicitly trigger it, for example:

  • tapping "Locate me",
  • tapping a building on the map,
  • searching for nearby addresses,
  • resolving an address through search.

There is no background location access, and the app itself keeps no location history. When you trigger one of the actions above, your GPS coordinates are sent directly to the adiresy.mg API to answer that specific request (see section 3.5). According to adiresy.mg, coordinates are not retained beyond the duration of the request and are not shared with further third parties.

3.2 Anonymous device registration

The first time the app needs to reach the server, it automatically and anonymously registers an access token (POST /api/v1/auth/device/register/), used only to guard against abuse and enforce request limits. Only the following is sent:

  • the platform name ("android"),
  • the app version.

No device ID, advertising ID, IMEI, or other persistent device identifier is transmitted. The resulting token is stored only locally (see section 5) and attached to further requests via the X-Adiresy-Key HTTP header.

3.3 Connection data (IP address)

As with any internet connection, the server being contacted (the adiresy.mg API or GitHub, see 3.5) necessarily sees the device's IP address as a technical part of the request. The app itself does not store, log, or otherwise process the IP address.

3.4 Data stored only on your device

The following stays only on your device and is never uploaded or synced to any server:

DataPurpose
Favourites / bookmarksAddress code, coordinates, optional name/description — for quickly finding saved places again
Search historyrecently entered search terms, to show recent searches
Language and theme settingspersonal app preferences
Offline map datadownloaded map tiles for offline use

All of this can be viewed, exported, or deleted at any time via Settings → Offline map data or the bookmark export/import tools, and everything is removed when the app is uninstalled.

3.5 Sharing with third parties

RecipientPurpose / scope
adiresy.mg An independent operator, unrelated to this app's project (described by them as a volunteer team). GPS coordinates and search queries are sent directly from your device to their servers when you use features like location search, address resolution, or nearby search. adiresy.mg does not have its own published privacy policy at the time of writing; they can be reached via adiresy.mg/contact.
GitHub, Inc. Offline map data (.pmtiles files) is downloaded as public release files from the nynosy/adiresy-tiles repository. GitHub's own privacy policy applies to these downloads.

No data is shared with advertising networks, analytics providers, data brokers, or any other third party.

4. Permissions at a glance

PermissionPurpose
INTERNETNetwork access for API requests and map data downloads
ACCESS_NETWORK_STATEDetecting connection status (e.g. for Wi-Fi-only downloads)
ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATIONsee section 3.1

The app requests no further permissions — in particular, no access to the camera, contacts, microphone, SMS, or storage outside its own app directory.

5. Data security

  • All network communication uses HTTPS/TLS only. Unencrypted HTTP is blocked by Android's default network security policy.
  • The locally stored API token is encrypted with AES-256 where supported by the platform (Android EncryptedSharedPreferences).

6. Retention

  • Server-side (adiresy.mg): per their statement, coordinates are not retained beyond the duration of the request.
  • On-device: until you delete it yourself, or until the app is uninstalled.

7. Your rights

Since the app has no accounts and no personal data is retained server-side, several of the rights below have little practical data to act on — but in general, you have the right to:

  • Access the data concerning you
  • Have inaccurate data corrected
  • Have data deleted
  • Restrict processing
  • Data portability
  • Object to processing

To exercise any of these, use the contact details in section 1.

You also have the right to lodge a complaint with a data protection supervisory authority.
